# AutoCRO

Proof of concept of a **self-optimising website**: a fictional webshop (Fjeldspor) tracked with GA4 ecommerce events,
where Claude analyses behaviour, writes hypotheses, builds and runs A/B tests on simulated shoppers, and ships or kills
changes by fixed decision rules. Built and operated by Claude for IMPACT Commerce.

- Live shop: https://crole-gregersen.github.io/autocro/
- Operating manual: [AUTOCRO.md](AUTOCRO.md) · Decisions: [docs/decision-log.md](docs/decision-log.md) · Backlog: [docs/hypothesis-backlog.md](docs/hypothesis-backlog.md)

Fjeldspor is fictional. No real products are sold and no real orders are placed.
